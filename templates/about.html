Project overview, technology stack, and system architecture

Project Overview

The Smart Dairy Livestock Monitoring and Decision Support System is an AI-powered web application designed to assist dairy farm managers and veterinarians in monitoring the health of dairy animals in real time.

By leveraging machine learning algorithms trained on physiological and environmental data, the system can predict whether a dairy animal is healthy or at risk, and provide actionable smart recommendations to improve animal welfare and farm productivity.

This system was developed as a Major Computer Science Project, demonstrating the application of Artificial Intelligence in the agricultural domain (AgriTech / Precision Farming).

System Modules

Module 1: Health Prediction

Uses a trained Random Forest classifier to predict livestock health status.

  • 3 algorithms compared: DT, RF, LR
  • Best model auto-selected by accuracy
  • Outputs: Healthy / Sick + Confidence %
  • 6 physiological input features
  • Target accuracy ≥ 85%
Module 2: Smart Recommendations

Rule-based decision support engine generating veterinary and management advice.

  • Temperature threshold alerts
  • Humidity & ventilation guidance
  • Nutrition & feed recommendations
  • Isolation protocols for sick animals
  • Dynamic, context-aware output
